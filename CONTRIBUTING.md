# Contributing

1. Fork the repo and create a branch: `git checkout -b my-change`
2. Set up: `pip install -e ".[dev]"`
3. Make your change and add a test in `tests/`
4. Run `pytest` and make sure it passes
5. Open a pull request describing what and why

Ideas: filter by author, CSV export, commits-per-month chart, ignore patterns for hotspot files.
